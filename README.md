## 📁 웹사이트 구조 (Page Structure)

1. **`index.html` (HOME)**:
   - 클린 & 프리미엄 랜딩 페이지.
   - 브랜드 핵심 가치 및 4대 USP 요약, 감성 컬러웨이 룩북.
   - 사전예약 원클릭 모달 연동.

2. **`product.html` (PRODUCT)**:
   - 7단계 상세 스토리텔링:
     - Section 1: Hero & 360° 인터랙티브 턴테이블 뷰어 (Front, Side, Back 드래그/클릭).
     - Section 2: 육아 페인포인트 3가지.
     - Section 3: 문제 해결 솔루션 비교.
     - Section 4: 4대 핵심 기능 인터랙티브 시뮬레이터 (성장 패널, 마그네틱 스냅, 스마트 감온 패치, 소매 롤업).
     - Section 5: 상세 스펙 및 세탁 가이드.
     - Section 6: 투명한 사전 체험단 영상 (최신 1080p 고화질 영상) + 실제 부모님 100% 생생 영상 후기 3종.
     - Section 7: 얼리버드 라인업 & 사전예약 CTA.

3. **`about.html` (ABOUT)**:
   - 브랜드 철학, 타협하지 않는 3가지 원칙.
   - 실제 구매 부모님들의 리얼 영상 리뷰 쇼케이스.

4. **`contact.html` (CONTACT)**:
   - 자주 묻는 질문(FAQ) 아코디언.
   - 1:1 온라인 문의 폼.
   - 공식 고객센터 운영 안내 및 직통 연락처.

  - 비디오 리뷰 동시 재생 제어 및 플레이어 인터랙션.

## 🚀 로컬 실행 방법 (How to Run)

### 방법 1. 브라우저에서 직접 열기
`index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge) 등 웹 브라우저에서 바로 열 수 있습니다.

### 방법 2. 로컬 웹 서버 실행 (권장)
Python이 설치되어 있는 경우 터미널에서 아래 명령어를 실행하면 최적의 환경에서 확인하실 수 있습니다:
```bash
python -m http.server 8080
```
브라우저 주소창에 `http://localhost:8080` 을 입력하여 접속합니다.
